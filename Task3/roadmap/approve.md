### Обоснование Roadmap.

![Roadmap](Task3/roadmap_img.png)

Q1. Запланировано разделение на домены для независимого развития проектов внутри системы. Уменьшение связанности позволит быстрее внеднять новые релизы, увеличит отказоустойчивость системы и позволит гибко масштабировать высоконагруженные модули.
Q2. Запланироваы работы по разработке аналитического ранилища данных для портала. Выбор Базы данных обусловлен высокой производительностью БД Clickhouse для получения сложных аналитических запросов, которые используются при генерации отчетов. Такое хранилище улучшит производительность генерации отчетов и разгрузит основную базу данных DWH(SQL Server).
Q3. Запланировано создание витрины данных, через которую будет происходить взаимодейтвие с базой данных. Это улучшит пользопательсктй опыт взаимодействия с системой и инкапсулирует "внутреннюю кухню" хранилища данных. Также запланировано функциональное и нагрузочное тестирование для повышения качества продукта.
Q4. Запланирвоан вывод в продакшн среду с использованием канареечных релизов. Только при успешном взаимодействии портала с фокус-группой, будет расширен трафик на более широкую группу. Это поможет избежать рисков при сбоях в системе портала.
